### 场景 4：周末 / 月末效能复盘 · 专属 AI 时间教练

## 🌟 核心功能与特色

### 1. 🔄 全自动无感记录 + 智能去水防挂机
- **无感捕捉**：深度融入思源工作流，只要你在阅读或编辑文档，插件便会自动记录；文档切换时无缝结转，无需手动开始/暂停。
- **精准防挂机**：监听鼠标移动、滚轮滑动与键盘输入。离开电脑超过设定阈值后，自动将该段闲置时间精准扣除，确保统计无水分。

### 2. 📅 日 / 周 / 月三重视图全景透视
- **日视图（Day View）**：
  - **24 小时纵向时间轴**：按时间先后直观展示全天各时段的活动时间块（Time-blocking）。
  - **实时红线指示**：动态标记当前时间进度，清晰感知全天节奏。
  - **活动清单**：右侧罗列当日每段专注会话明细与闲置扣除记录。
- **周视图（Week View）**：
  - **7 天对比热力网格**：周一至周日横向对比，看清一周精力的高峰与低谷。
  - **日期快速下钻**：点击任意一天的日期表头，直接跳转查看该日的 24 小时细分时间槽。
- **月视图（Month View）**：
  - **整月日历矩阵**：以热力颜色深浅直观呈现整月每日专注强度。
  - **文档标签概览**：在日历格中直观显示当日主攻的核心文档。

### 3. 📊 5 大核心效能指标 + 交互式图表
看板顶部实时提炼 5 项关键个人效能 KPI：
1. **周期总专注时长**：净有效工作与学习时间。
2. **日均 / 峰值专注时长**：评估平均产出与单小时最高投入。
3. **专注会话总数与均长**：衡量单次专注深度，判断是否过度碎片化。
4. **闲置扣除时长**：清晰展示剥离的挂机时间，数据真实可信。
5. **主攻重心与占比**：快速识别投入精力最多的 TOP 文档及比重。

**联动可视化图表**：
- **文档投入分布环形图**：直观展示精力投向了哪些文档与主题。
- **时段走势与对比图**：日视图 24 小时分布柱状图、周视图每日对比图、月视图专注走势面积图。

### 4. ⚡ 双向交互直达思源文档
- 看板中的任意时间块、活动清单记录或文档标签，均支持**鼠标点击一键在思源笔记中打开对应文档**，复习、续写零阻碍。

### 5. 🤖 一键导出 AI 复盘总结
- 点击右上角 **「导出 AI 总结」**，一键复制包含**当前周期统计数据、文档投入排行榜与专业高效能教练 Prompt** 的完整内容，直接粘贴给任意 AI 助手获取诊断建议。

### 6. 🔒 100% 本地优先，隐私绝对安全
- 所有时间数据以标准轻量 JSON 文件保存在思源工作空间本地。
- **0 网络上传、0 云端依赖**，全面保护你的知识库与时间轨迹隐私。

## 🚀 极简上手流程

```
[1. 集市安装启用] ──> [2. 照常使用笔记（后台静默记录）] ──> [3. 点击顶部 ⏱️ 查看看板与复盘]
```

1. **安装插件**：在思源笔记「设置」-「集市」-「插件」中搜索 **源时记**，点击安装并启用。
2. **照常工作**：无需任何配置，像平常一样在思源中阅读、写作、整理知识，插件在后台静默运行。
3. **打开看板**：点击顶部工具栏的 **⏱️（源时记图标）**，即可呼出全屏时间分布与专注分析看板。
4. **查看与复盘**：在右上角自由切换 **日 / 周 / 月** 视图；点击任意日期下钻，或点击 **「导出 AI 总结」** 获取 AI 效能指导。

## 💬 常见问题 (FAQ)

<details>
<summary><b>Q1: 插件在后台运行会消耗电脑性能或拖慢打字速度吗？</b></summary>
完全不会。源时记采用超轻量级的事件节流监听机制，仅在文档切换与状态变更时进行极少量的本地计算，内存占用极低，完全不影响打字和笔记流畅度。
</details>

<details>
<summary><b>Q2: 如果我打开文档后去倒水或者离开电脑，时间会一直记录吗？</b></summary>
不会。插件内置了智能闲置检测机制，一旦超过设定时间没有键盘输入、鼠标移动或滚轮操作，系统会判定为发呆/离开，并在你返回后自动扣除这段无效时长。
</details>

<details>
<summary><b>Q3: 我的时间统计数据存储在哪里？更换电脑或备份如何处理？</b></summary>
所有数据均存储在思源工作空间的本地插件数据目录下（按每日独立 JSON 保存），随思源笔记本身的云端同步或本地备份一同保存，安全可靠。
</details>
