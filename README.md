# 量化时间痕迹，助你高效复盘——“源时记”（自动记录与专注分析插件）功能预览

## 💡 为什么你需要「源时记」？

在日常使用思源笔记进行**学术研究、考研考公、主题写作、专业学习或项目管理**时，你是否常有这样的困惑：

- 🕒 **忙碌一整天，却不知时间去哪了**：文档开了关、关了开，到夜晚回想，只有疲惫和模糊印象，缺乏可量化的成就感。
- 🛑 **传统打卡工具极易打断沉浸心流**：无论是番茄钟还是各类第三方计时器，都需要频繁手动点击“开始 / 结束”，一旦遗忘打卡便前功尽弃，甚至为了记录时间而分心。
- 💦 **离开挂机导致统计严重“注水”** ：偶尔起身接水、看手机或发呆，传统计时器依旧盲目走字，生成虚假的“8小时专注”，陷入自我感动。
- 📉 **周期复盘缺乏系统数据支撑**：周末或月末想要优化学习与工作节奏，却无法直观看出自己在各课题、文档上的实际精力倾斜与时间黑洞。

 **「源时记」专为解决上述痛点而生**——它深度嵌入思源笔记，在后台静默、全自动地捕捉你在每篇文档上的真实专注轨迹，自动剔除无效闲置，并以丰富直观的日 / 周 / 月看板与 AI 智能教练，助你重塑深度工作与高效学习节奏。

## 🌟 核心功能一览

### 1. 🔄 全自动无感追踪

- **随开随记**：打开任意笔记或切换文档时，后台自动无缝结转统计，无需手动干预。
- **零心流打扰**：让你彻底沉浸在思考、阅读与写作中，无需为“记时间”而额外耗费精力。

### 2. 🛡️ 智能去水防挂机

- **毫秒级外设感知**：实时监听键盘敲击、鼠标移动、滚轮滚动与触控事件。
- **精准剥离闲置**：当检测到离开电脑或长时间停止交互超过阈值后，自动将该段无操作时长判定为闲置并精准扣除，确保统计数据 100% 真实客观。

### 3. 🎯 专注目标设定与动态预设

- **周期目标管理**：支持为每日、每周或每月设立核心专注宣言（如  *“攻克第 4 章专业课考点，专注 4 小时”* ）。
- **智能场景推荐**：根据当前所选的日历维度（日 / 周 / 月），智能推荐匹配的目标候选词，一键设定。
- **全流程贯穿**：目标常驻于看板顶部 Hero 卡片，并在 AI 复盘时作为核心基准进行达成度评估。

### 4. 📅 日 / 周 / 月全景透视看板

|视图类型|核心呈现|适合解决的分析需求|
| :-------| :-------| :-----------------------------------------------------------|
|**日视图 (Day)**|**24 小时纵向时间轴 (Time-blocking)**  + **实时红线进度指示** + **活动会话明细清单**|掌握今天的时间流向与作息节律，回溯每段专注的具体时段与耗时。|
|**周视图 (Week)**|**7 天横向热力柱对比** + **每日投入趋势** + **表头一键下钻单日**|评估周内工作日与周末的精力波动，找出精力充沛的黄金时段。|
|**月视图 (Month)**|**整月日历热力矩阵** + **每日核心专注文档标签** + **月度专注走势图**|宏观洞察整月持续性与专注习惯养成，回顾各阶段主攻重点。|

### 5. 📊 5 大核心效能 KPI + 交互式可视化图表

看板顶部实时提炼 5 项关键个人效能指标：

1. **周期总专注时长**：剔除闲置后的净有效工作与学习时长。
2. **日均 / 峰值专注时长**：衡量持续输出能力与单日/单小时最高投入。
3. **专注会话总数与平均均长**：评估单次专注深度，判断是否过度碎片化切换。
4. **闲置扣除时长**：清晰展示系统为你剥离的无效发呆挂机时间。
5. **主攻核心与比重**：直观展示投入精力最多的 TOP 文档及百分比。

**联动图表**：

- **文档投入分布环形图**：多维度展示时间在各个文档上的投入切片。
- **时段走势与对比图**：日分布柱状图、周对比折线图、月趋势面积图。

## 🚀 快速上手

### 1. 开启全自动追踪

- 安装并启用本插件后，时间追踪服务将**自动在后台启动**。
- 你只需像平常一样在思源笔记中阅读、编辑、构思文档，无需任何额外操作。

### 2. 打开看板

- 点击思源笔记**顶部工具栏的「源时记」时钟图标**，即可打开专注看板。
- 可在插件设置中选择默认以**新页签**打开或以**弹窗**形式打开。

### 3. 设定你的专注目标

- 在看板顶部的**专注目标**卡片中，输入今日 / 本周 / 本月的核心目标，为专注指引方向。

![image](https://raw.githubusercontent.com/famotime/siyuan-time-spent/main/assets/image-20260925164140-fgn474e.png)

### 4. 探索日 / 周 / 月数据与 AI 复盘

- 点击顶部右上角的 **日视图 / 周视图 / 月视图** 切换不同时间跨度。
- 点击右上角的  **「AI 总结」**  按钮，一键获取专属时间教练的深度复盘与改进建议。

## ⚙️ 常见问题 (FAQ)

- **插件在后台记录会拖慢思源笔记或影响打字流畅度吗？**   
  完全不会。源时记针对事件监听进行了严格的节流与轻量化处理，仅在文档切换和状态变更时进行极低开销的本地存储，内存占用极小，保障你的打字与笔记体验始终丝滑流畅。
- **如果我打开文档后离开电脑去吃饭或开会，时间会被算进去吗？**   
  不会。插件内置智能闲置感知机制，当检测到超过预设阈值没有任何键盘输入、鼠标移动、滚轮滚动或触控交互时，会自动判定为离桌闲置，并在你返回后将这段无操作时间精准扣除，绝不计算进“净专注时长”。
- **我的时间数据存储在哪里？更换设备后如何迁移？**   
  所有数据以标准 JSON 格式保存在当前思源工作空间的 ​`data/storage/petal/siyuan-time-spent/` 本地目录下。只要你使用了思源官方云端同步或定期备份工作空间，数据就会自动同步至新设备，安全可控。
- **AI 深度复盘功能如何使用？必须配置 API 吗？**   
  AI 深度复盘提供两种使用方式：

  1. **内置一键生成**：在插件设置中填写任意兼容 OpenAI 格式的大模型 API 地址与密钥（或通过 *API 旋钮* 插件一键接管），即可在看板内直接点击「AI 总结」流式生成分析；
  2. **免 API 复制模式**：即使未配置 API，点击「AI 总结」弹窗中的「复制 AI 分析 Prompt」，即可将完整的结构化数据与精心调优的教练提示词一键粘贴给 ChatGPT、Claude、Kimi 等任意外部 AI 使用。
