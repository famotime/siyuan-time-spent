# 思源笔记时间追踪插件 (SiYuan Time Spent) - 设计规范

## 1. 设计理念 (Design Philosophy)
参考开源项目 [OpenTickly](https://github.com/CorrectRoadH/OpenTickly) 的核心理念，本插件旨在为思源笔记提供**“无感记录，直观呈现，AI赋能”**的时间追踪能力。
设计上追求极简的记录过程与丰富的可视化展示，使数据不仅仅是冰冷的数字，而是展现用户知识管理和思维流动的“时间画布”，兼具极高的实用性与艺术性。

## 2. 色彩与主题 (Color & Theme)
- **主题适配**：深度集成思源笔记的深色/浅色模式，但在插件独立的仪表板中，采用更具高级感的现代 Web 设计语言（如暗黑模式下的低对比度背景与高亮色块）。
- **智能色块分配**：
  - 为不同的“笔记本”、“目录”或“标签 (Tags)”自动分配莫兰迪色系或低饱和度霓虹色（例如：紫色、橙色、薄荷绿、海浪蓝等）。
  - 在时间轴和日历视图中，相同的文档或标签会呈现一致的颜色，形成错落有致、极具视觉辨识度的色彩分布，类似 OpenTickly 的分类展示。
- **排版 (Typography)**：采用现代化无衬线字体（如 Inter 或 Roboto，默认跟随思源），确保图表、数字面板和时间轴在密集数据下的极佳可读性。

## 3. 核心视图设计 (Core Views)
### 3.1 时间轴/日历视图 (Timeline & Calendar)
- **日视图 (Day View)**：纵向时间轴展示一天内访问不同文档的先后顺序和精确停留时长。
- **块状设计**：每个文档的访问会话渲染为带有圆角 (`border-radius: 6px` - `8px`) 的色块。
- **悬浮态 (Hover)**：鼠标悬停色块时，展示带有 Glassmorphism (毛玻璃) 效果的悬浮提示框 (Tooltip)，清晰显示“文档标题、具体时长、起始时间、文档路径”。

### 3.2 分析仪表板 (Analytics Dashboard)
- **KPI 面板**：位于顶部，使用超大号字体展示今日总专注时间、本周总记录时间等核心数据。
- **环形分布图 (Donut Chart)**：直观展示在不同笔记本、不同标签上花费的时间比例。
- **活跃度热力图 (Heatmap)**：仿照 GitHub 的贡献图，展示一年内每天的笔记活跃情况，颜色深浅代表当天的专注时长。
- **访问排行 (Top Documents)**：条形图展示“最常访问 / 耗时最长”的 Top 10 文档。

## 4. 动效与微交互 (Micro-interactions)
- **平滑过渡**：时间范围切换、视图切换时提供平滑的淡入淡出动画。
- **交互反馈**：鼠标悬停在图表元素或时间块上时，色块边界微微发亮或上浮，增强界面的生命力和用户的操作反馈感。
