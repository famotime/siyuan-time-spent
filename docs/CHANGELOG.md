## 版本 v0.9.1 (番茄钟心流舱重构)

**v0.9.1** 对番茄钟做了一次从“换皮”到“产品能力层”的重构。在完全保留既有功能行为的前提下，把番茄钟从一个标准倒计时圆环，重塑为有节奏、有守护、有氛围的「心流舱 Flow Pod」。

### 产品能力
1. **番茄周期叙事**：补齐番茄工作法正统节奏——每轮 4 颗（可配置 2-8 颗）后进入长休息（默认 15 分钟）。表盘下方新增轮次轨道，已完成 / 进行中 / 待完成三态可辨；长休息拥有独立的更冷色温与仪式和弦。
2. **离桌守卫**：复用被动追踪的闲置探测器（同一实例与阈值），专注期间长期无操作时表盘凝滞并提示“离开中”，归来时温和告知离开时长。**完整墙钟时长仍计入有效专注**，离桌时间仅写入 `idleTime` 作留痕，统计口径与旧版一致。
3. **打断记录**：暂停时可轻量记录“刚才发生了什么”，随本次专注一并归档到时间日志备注，让每一次分心都被看见而非干脆丢弃。
4. **智能时长推荐**：综合今日已专注量、所处时段与轮次进度，在待机时给出一个推荐时长与理由，点击即用。
5. **键盘驱动**：`Alt+P` 开关面板、`空格` 暂停 / 继续、`Esc` 关闭。三重 guard 确保焦点在正文编辑器时空格仍正常输入。

### 设计与交互
6. **三大表盘彻底差异化**：三者共享氛围层与色温通道，只替换叙事载体——极光流体的多层弧带漂移与能量核、精密机械的 60 格刻度与真实扫视指针、时空沙漏的漏斗收缩与下腔结晶。中心数字统一放大到 56px，成为绝对视觉锚点。
7. **色彩温度迁移**：新增 `--pomo-heat` 通道，专注中主色随进度由宿主主题色缓慢爬向琥珀（注意力升温隐喻），休息迁移青绿、长休息更冷、凝滞去饱和。全程跟随任意第三方思源主题。
8. **氛围与仪式**：环境粒尘缓慢上浮、达成时全屏 2 秒微时刻自动消散、休息阶段 4-4-6 呼吸引导光环与文字双轨同步。
9. **动效强度配置生效**：「沉浸克制 / 灵动充沛」从原本未消费的死配置变为真实开关，与系统「减少动态效果」形成双通道降级。
10. **控件瘦身**：时长选择从 8 个控件收敛为推荐芯片 + 4 预设 + 表盘滚轮微调。

### 工程质量
11. **架构拆分**：696 行的 `StatusBarTimer.vue` 按“数据获取 / 视图模型 / 呈现”三层拆为 17 个文件，派生计算全部上收进 `usePomodoroPresenter`。
12. **规范整改**：清除全部小于 12px 的文字、清退全库 emoji 图标（含日历里的番茄徽章）、浮层改回实体底色。
13. **新增 SFC 体检**：`npm run check:sfc` 弥补 `typecheck` 不检查 `.vue` 内部、esbuild 只剥离类型的盲区，并借此修复了 3 处此前不可见的真实缺陷。

## 版本 v0.9.0 (阶段一 P0 核心体验闭环)

**源时记（siyuan-time-spent）v0.9.0** 重点补齐了原版本的四大核心体验短板，实现“主动冲刺与被动底噪协同”、“移动与平板端覆盖”、“每日日记自动化静默沉淀”与“离桌归因补录”四大关键飞跃：

### 核心功能与重大改进
1. **主动专注与状态栏番茄钟双模引擎**：
   - 底部状态栏常驻轻量计时胶囊，支持实时显示当前专注文档或 `🍅 24:59` 倒计时；
   - 点击状态栏展开控制面板，支持 25m/45m/60m 冲刺与正向秒表，支持暂停、继续与提前完成；
   - 计时采用真实时间戳对齐，防休眠滞后；番茄达成后调用 Web Audio API 播放纯代码合成和弦提示音；
   - 在 24 小时时间轴与活动清单中以金色高光边框和 🍅 徽章独立标出番茄钟会话。
2. **思源移动端与平板端全量自适应**：
   - 在 `plugin.json` 中解锁 `mobile` 与 `browser-mobile` 前端权限，全面支持 iPad、安卓平板与手机端；
   - 增加移动端后台挂起生命周期守卫（`visibilitychange`），App 切至后台时立即结转落盘，杜绝丢数据；
   - `IdleWatcher` 增强触摸滑动（`touchmove`/`touchend`）手势感知，窄屏自适应响应式排版。
3. **Daily Note 每日专注数据自动化静默沉淀**：
   - 新增 `DailyNoteArchiver` 服务，通过思源内核 SQL 与块 API 自动探测当日日记；
   - 看板顶栏新增【归档到日记】按钮，一键将今日净专注、去水时长、番茄数与主攻文档以折叠块格式注入日记；
   - 采用属性标记查询与 `updateBlock`/`appendBlock` 实现幂等写入，防重复生成垃圾块。
4. **离桌唤醒归因引导与时间轴手动补录**：
   - 新增 `AfkPromptModal` 气泡：离桌超时唤醒后支持将离桌时间一键归因为“线下学习/纸质做题”并计入有效时长；
   - 新增 `ManualLogModal` 弹窗：支持在看板日视图中直接补录指定文档的专注时间；
   - 日视图右侧活动清单支持单条会话记录一键删除确认。

## 首个发布版本 v0.8.0

**源时记（siyuan-time-spent）** 是一款专为思源笔记打造的**全自动时间追踪与专注效能分析插件**。旨在帮助用户在考研备考、长篇写作、专题研究与日常学习中，精准量化各文档上的真实精力投入，辅助科学复盘。


### 解决的核心痛点
- **拒绝心流打扰**：无需频繁手动打卡或点击番茄钟，后台静默自动统计。
- **智能去水防挂机**：自动感知键盘与鼠标交互，精准识别并扣除离桌闲置时间，避免虚假努力。
- **告别无感耗时**：解决“忙碌一天却不知时间花在哪”的困惑，提供可视化的时间流向与复盘依据。


### 核心功能特性
1. **全自动无感追踪与去水机制**：
   - 切换或打开文档即刻自动计时；
   - 毫秒级外设事件感知，超时无操作自动扣除闲置时长。
2. **多维度全景透视看板**：
   - **日视图**：24 小时纵向时间轴（Time-blocking）、实时进度线与会话清单；
   - **周视图**：7 天投入柱状对比与趋势分析，支持下钻单日；
   - **月视图**：整月日历热力矩阵、每日核心专注文档标签与月度走势。
3. **效能指标与交互式图表**：
   - 提炼 5 大核心 KPI（净专注时长、日均/峰值、会话均长、闲置扣除量、主攻文档分布）；
   - 提供文档投入分布环形图与时段对比图表。
4. **看板与笔记双向直达**：
   - 点击看板中的时间轴色块、活动清单或热力标签，可直接在思源中跳转并打开对应笔记。
5. **周期专注目标与 AI 深度复盘**：
   - 支持设置日/周/月核心专注目标；
   - 支持直连 OpenAI 兼容大模型 API（或由 `siyuan-api-switch` API 旋钮接管），一键生成结构化诊断建议；同时提供免 API 的 Prompt 复制模式。
6. **100% 本地优先与隐私安全**：
   - 数据以标准 JSON 存储在工作空间本地目录（`data/storage/petal/siyuan-time-spent/`），不上传任何云端，支持随思源官方备份同步。
