# 当前实现：专注一页（2026-10-02）

> 以下为本轮已落地规范；后文保留历次设计讨论作为历史，不代表当前 UI。

- **设计焦点**：笔记上下文、可读时间和清晰主动作。三表盘保留 `zen / chrono / hourglass`，展示名统一为光环、刻度、沙漏；页签形游标成为共同视觉语言。
- **减少干扰**：面板是非模态 dialog，点编辑器关闭但不吞点击；完成状态嵌入面板或状态栏，不覆盖整屏。启动不强迫填写目标。
- **渐进披露**：默认三个快捷时长和自定义入口；自定义包含全部预设、整数输入和可选推荐。运行态不展示外观/时长设置。打断记录与呼吸引导由用户主动打开。
- **真实数据**：今日摘要只汇总已保存番茄日志，按开始日期归档，提前结束也计入记录次数。它与仅存内存的本轮计数不同。少于10秒不落日志，保存失败不会增长摘要；宿主已吞掉的底层 I/O 错误无法由插件重新识别。
- **兼容边界**：不改墙钟、AFK不扣时长、长短休息和放弃不保存的规则；不增加自动写笔记、跨重载恢复或第四种表盘。

**Plan: 番茄钟组件的创意重设计（亮 / 暗双主题，去 AI-Slop）**

**1. 设立设计方向与视觉语言**

- 确立一个有辨识度的主题概念，替换现有的靛蓝配色。建议以"番茄"本身为灵感做一套克制的暖色系（番茄红 / 熟果橙做点缀，中性灰做骨架），让专注、暂停、休息三种状态各有清晰的性格，而不是千篇一律的高饱和渐变。
- 定义每种状态的情绪：专注时沉稳有推进感、暂停时安静收敛、休息时轻松通透，用颜色、动效节奏和图标语气来区分。
- 全程验证亮色与暗色两套主题下的可读性与对比度，确保时间数字、进度、按钮在任一主题都清晰不刺眼。

**2. 重塑状态栏入口（常驻胶囊）**

- 把状态栏那颗小胶囊从"图标 + 时间"升级为更有生命力的微型形态：例如一圈随剩余时间收缩的细进度环、专注时的呼吸律动、休息时的柔和色调切换。
- 让胶囊在不同状态下一眼可辨（在专注、暂停、休息、待机之间用颜色和微动效区分），同时保持体积小巧、不打扰笔记书写。
- 保证点击、悬停有明确反馈，且在浅色和深色状态栏上都协调。

**3. 重新设计弹出的专注面板**

- 重做中央的计时表盘，作为整个面板的视觉主角：更精致的环形进度、更有张力的时间数字排布，并加入平滑而克制的过渡动效（避免生硬跳动）。
- 优化待机态的设置区：让"倒计时 / 秒表"切换、快捷时长、自定义时长的滑块与步进更直观、更有手感，减少拥挤感。
- 重排专注 / 暂停 / 休息三种状态下的操作按钮布局，让最常用的操作最突出，"放弃"等危险操作依旧安全防误触。
- 保留并美化"当前关联笔记"提示、状态徽章、以及底部跳转看板的入口。

**4. 加入有记忆点的动效与反馈细节**

- 为关键时刻设计恰到好处的动效：开始专注、完成一颗番茄、进入 / 结束休息时给予有仪式感但不喧闹的视觉反馈。
- 让进度推进、暂停恢复、状态切换都有连贯顺滑的过渡，强化"时间在流动"的感受。
- 与现有的完成提示音、系统通知配合，形成视听一致的收尾体验。

**5. 双主题打磨与整体一致性收尾**

- 在亮色与暗色主题下逐一核对每个状态和每个控件，修正对比度、边框、阴影与毛玻璃背景的表现。
- 确保重设计后的番茄钟与插件其它界面（看板、图表等）风格协调，不显突兀。
- 保持所有现有功能（倒计时、秒表、暂停 / 继续、提前完成、放弃、短休息跳过 / 延长、时长记录、多语言文案）行为不变，只更新外观与交互质感。

# 资深互联网 UX 设计师重构方案与落地规范

## 一、 UX 核心设计哲学：从“催促机器”到“心流伴侣”
市面上绝大多数番茄钟插件之所以充满“AI Slop（廉价模板感）”，原因在于它们只是套用一个标准的 SVG `stroke-dashoffset` 圆环涂上写死的高饱和色彩，机械递减数字。在深度知识管理与写作场景下，番茄钟应遵循**“边缘交互（Peripheral Interaction）”**法则：
- **无事时若隐若现**：常驻状态栏不抢夺写作主视线，余光一扫即可通过微环弧度感知剩余进度；
- **操作时极富质感**：提供阻尼物理滑动、分段发条卡点、微弹与柔光动效；
- **达成时成果结晶**：将时间抽象消耗转化为“知识成果的凝结”，触发仪式感正向多巴胺反馈。

## 二、 原生色彩自适应架构（No AI-Slop）
- 全面解耦写死的 Tailwind 硬编码色，深度绑定思源原生 CSS 变量：
  - 主品牌色：`var(--b3-theme-primary)`
  - 底板与表面：`var(--b3-theme-surface)` 与 `var(--b3-theme-background)`
  - 主次文本：`var(--b3-theme-on-background)`、`var(--b3-theme-on-surface)`
- 通过 CSS `color-mix(in srgb, var(--b3-theme-primary) X%, transparent)` 与 `backdrop-filter: blur(16px)` 动态派生漫射光晕与亚克力毛玻璃，天然完美兼容亮色、暗色及任意第三方社区主题。

## 三、 三大创意交互形态系统（设置面板与浮层内自由热切换）
1. **禅意流体 (Zen Flow)**：
   - 极简呼吸光环，多层柔光流体律动；
   - 随时间推进自然收缩漫射，伴随约 12 次/分人体舒缓节拍；
   - 专为深度思考、阅读精读、沉浸写作设计。
2. **精密机械 (Chrono Dial)**：
   - 致敬工业钟表与潜水腕表单向旋转表圈（Rotating Bezel）；
   - 360° 分布 60 格精密分度微刻度，随进度逐格点亮；
   - 搭载秒针扫视微探针（Sweep Pip）与 Tabular 等宽工程数字。
3. **时空沙漏 (Hourglass Sand)**：
   - 现代双漏斗微晶沙漏结构，上层光子沙粒穿透颈部，下层积蓄堆叠成知识晶体；
   - 倒计时归零时迸发微光波纹涟漪（Bloom Ring），提供强正向成就回馈。

## 四、 关键触点交互重塑
- **状态栏微胶囊 (Ambient Micro-Capsule)**：
  - 内嵌 16px 矢量微进度环，随时间流逝平滑闭合；
  - 运行态伴随轻微呼吸光点，悬停微弹（`scale(1.02)`）；
  - 休息态平滑切换为舒缓水波色温。
- **浮动面板 (Focus Popover)**：
  - 顶部直接内嵌皮肤形态快速分段切换器；
  - 强化关联笔记呈现，突出当前写作上下文；
  - 待机区提供 15/25/45/60 快捷气泡与自由滑块微调；
  - 防误触放弃二次确认卡片；
  - 休息阶段提供呼吸引导（“吸气 · 舒缓神经”、“呼气 · 放松肩颈”）。

## 五、 工程落地架构

# 二轮重设计补充（2026-10-02）

上一版的三形态在落地后暴露出一个根本问题：**三者本质同构**——都是同一个 144px SVG 圆环加 24px 中心数字，只换了外圈装饰。这仍是典型的换皮，没有解决"脱颖而出"的诉求。因此本轮从产品能力层与视觉层同时重做。

## 用户在本轮确认的三项决策
1. **改造范围**：产品能力与视觉双突破（而非只改外观）；
2. **离桌守卫**：只提示、不扣除——检测并凝滞表盘、归来温和告知，但完整时长仍计入有效专注，`idleTime` 仅作留痕；
3. **形态策略**：保留三种，但彻底差异化。

## 落地的关键判断
- **轮次与长休息是番茄工作法的正统**，原实现完全缺失，补上后专注才有节奏与终局；
- **离桌守卫**复用被动追踪已有的 `IdleWatcher`（同一实例与阈值），零新增定时器、零侵入共享组件；在既有 500ms `tick()` 内轮询即可；
- **表盘差异化靠"共享氛围层 + 替换叙事载体"**：色温迁移、粒尘、呼吸、56px 排版三者共用，dial 只负责画弧带 / 刻度 / 沙粒，且三者的 props 契约完全对称，便于未来增删第四形态；
- **`uiPhase` 把冻结态映射为 `'paused'`** 是本次最重要的兼容技巧——所有既有的 `state === 'running'` 视觉分支自动走灰化，无需改任何一处 switch。

## 一个被忽略的工程盲区
`npm run typecheck` 只处理 `.ts`，**完全不检查 `.vue` 内部**；Vite 的 esbuild 也只剥离类型。两者都抓不到 `<script setup>` 里的未定义标识符——实测中 `settingsVersion` 未声明即使用，仍能通过 typecheck 与 build。为此新增 `npm run check:sfc`，把每个 SFC 的脚本体抽出后用继承项目 tsconfig 的临时配置统一编译。该工具随即暴露并修复了三处此前不可见的真实缺陷。

## 遗留事项
- 「一轮番茄数」与「长休息时长」尚未在看板 KPI 中体现，仅体现在时间轴标记与日记归档统计里；
- 轮次进度 `cycleCompleted` 目前仅存内存，**刷新或重载插件后会归零**，未持久化。若用户期待跨会话延续轮次，需要额外落地一个轻量存储；
- `pomodoroAnimationIntensity` 虽已接入真实开关，但「灵动充沛」下粒尘数量固定为 14，未随面板尺寸自适应。
