# 功能需求说明 (Features)

## 1. 自动无感时间追踪 (Auto Time Tracking)
- **自动化记录**：作为思源笔记的后台插件，当用户在编辑器 (Protyle) 中打开、阅读或编辑某篇文档时，插件自动开始计时，无需手动点击开始。
- **发呆/闲置检测 (Idle Detection)**：
  - 监控键盘输入、鼠标移动和点击。
  - 若无任何操作超过设定阈值（默认 5 分钟），系统自动暂停计时（标记为闲置）。
  - 当用户恢复操作时，自动恢复计时，并扣除闲置期间的时间，保证专注数据的真实性。
- **精准切换**：从文档 A 切换到文档 B、或是分屏操作时，插件能精准识别当前焦点所在的文档，自动结算文档 A 的时间，并开启文档 B 的计时。

## 2. 统计与多维度分布概览 (Dashboard & Distribution)
- **多维度统计**：
  - **按文档 (Document)**：单篇文档的累计投入时间。
  - **按笔记本/目录 (Notebook/Folder)**：某一知识体系下的总投入时间。
  - **按标签 (Tag)**：基于思源标签的时间聚类（如 #学习#、#工作#）。
- **时间范围筛选**：支持快速切换“今日”、“本周”、“本月”、“本年”及自定义日期范围。

## 3. 访问顺序与思维时间线 (Access Sequence & Timeline)
- **轨迹记录**：完整记录用户一天内的思维跳跃路径（例如：查看项目大纲 -> 搜索查阅参考资料 -> 编写主体文档 -> 回顾大纲）。
- **日历呈现**：通过类似 OpenTickly 的日历视图呈现，直观看出每天什么时间段在处理什么文档。支持点击时间线上的色块一键跳转回对应文档。

## 4. 数据导出与 AI 智能复盘 (Export & AI Review)
- **开放数据**：遵循本地优先原则，所有时间追踪数据保存在本地（JSON / CSV / SQLite 格式），并支持一键导出。
- **AI 复盘集成**：
  - 提取本周/本月的时间开销数据，生成适合大语言模型（如 ChatGPT / Claude）阅读的 Markdown 摘要。
  - 允许用户将摘要喂给 AI，让 AI 充当个人时间管理教练，帮你分析“时间去哪了”、“是否在某些文档上花费了过多的碎片时间”，以及“下一步优化建议”。
