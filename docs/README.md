# SiYuan Time Spent (思源时间追踪) - 设计文档

欢迎查阅 SiYuan Time Spent 插件的设计文档。本插件的设计灵感来源于优秀的开源时间管理工具 [OpenTickly](https://github.com/CorrectRoadH/OpenTickly)。

我们的目标是为思源笔记打造一款兼具**实用性**与**艺术性**的时间管理与分析插件，让使用者能够直观地了解自己在不同知识体系下的时间投入。
